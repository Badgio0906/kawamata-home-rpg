# 河俣さんのおうち帰れるかな

Godot 4.7.2 と GDScript で制作した短編コメディ RPG。職場から阪神尼崎駅へ、そして夜の街を抜けて自宅へ。食べ物の誘惑と向き合う全2ステージです。

## Play

GitHub Pages: https://badgio0906.github.io/kawamata-home-rpg/

## Controls

移動は自動です。食べ物に吸い寄せられるように、少し蛇行しながら歩きます。「ひと休み」ボタンまたは Space / P で一時停止・再開できます。

PC: 戦闘中は `1` 戦う、`2` 食べる、`3` 誰かを呼ぶ。画面上のボタンはマウスでも操作できます。

Mobile: 戦闘コマンドと「つづける」をタップ。移動操作は不要です。横向き推奨。

1ステージ目には一度だけ休めるベンチが3か所あります。食べるとHPとやる気が回復し、戦って勝つと経験値を得られます。レベルを上げると、一部のベンチでやる気も回復します。

## Stages

- **1：職場 → 阪神尼崎駅**。従来の遊びやすい難易度。駅で次のステージへ進めます。
- **2：阪神尼崎駅 → 自宅**。全8戦の上級コース。Lv.4、HP136、攻撃34、防御14、900 kcal、やる気80に揃えて出発します。1ステージ目の結果は集計に引き継ぎます。
- タイトルの「駅から出発・上級」から2ステージ目だけを遊ぶこともできます。失敗後は2ステージ目の開始時点から再挑戦できます。
- 2ステージ目の休憩は3戦目の後のHP60回復のみ。食事のタイミング、経験値、やる気による能力低下を考える必要があります。
- 7戦目の「超重量・二段ごちそう城」は回避できず、通常攻撃ではダメージを与えられません。助けを呼んでも倒せません（呼ぶ失敗時の消費なし）。**食べる2回、1回550 kcal、計1100 kcal** が必要です。その後にも最後の一戦が残ります。画面内に攻略用のカロリー目標は表示しません。
- 戦闘画面上部に勝利・食事の効果を表示します。結果の「食べた数」は食べて倒した敵の数で、二段ごちそうも1体と数えます。

## Verification

`godot --headless --path . --script tools/test_game.gd` で実際のゲーム処理を検証します。自動歩行・蛇行・一時停止・再戦防止、第1ステージの攻略・敗北、第2ステージ3攻略手順×200乱数シード、無計画な攻略の失敗、強制遭遇、2回食事、499/500 kcal境界、駅からの再挑戦を確認します。GitHub Actionsでも公開前に実行します。

`python tools/balance_stage2.py` は第2ステージの2187通りのコマンド計画を比較する補助シミュレーターです。実ゲームのテストを最終基準とします。

## Development

- Godot 4.7.2 stable / Compatibility renderer / single-threaded Web export
- GDScript
- `tools/generate_assets.py` でオリジナルのドット絵と音声を生成（実行時に Python は不要）
- 日本語フォント: Noto Sans JP (SIL Open Font License、`assets/fonts/OFL.txt`)
- 表示用ドットフォント: DotGothic16 (SIL Open Font License、`assets/fonts/DotGothic16-OFL.txt`)
- 見下ろしの街並み、詳細な新主人公の4方向歩行、64pxの食べ物モンスター、ドット絵の画面枠を採用。
- 食品モンスターの生成コード: `tools/generate_rpg_sprites.py`。新主人公・駅・二段ごちそうは `assets/rpg/` の生成済みPNGを使用し、素材再生成でも上書きされません。
- 建物素材・制作プロンプト: [assets/rpg/ARTWORK.md](assets/rpg/ARTWORK.md)

Godot エディターで `project.godot` を開いて実行できます。Web 書き出しは `export_presets.cfg` の Web preset を使用します。
